# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and no harassment of any kind. This applies in issues, pull requests, discussions, and anywhere else the project is represented.

To report unacceptable behavior, contact the maintainers privately through the repository's **Security** tab ("Report a vulnerability" reaches the maintainers without being public). Reports are handled confidentially.
